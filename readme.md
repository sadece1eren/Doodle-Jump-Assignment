# ▸ DOODLE JUMP

### A dark terminal-inspired arcade jumping game

<p align="center">
  <strong>Foundations of programming final project.</strong>
</p>

---

## Features

- Player movement with keyboard controls
- Automatically bouncing player mechanics
- Normal platforms
- Moving platforms
- Breaking platforms
- Increasing difficulty as you climb
- Score and high score tracking
- Game over and restart screens
- Debug overlay showing game information
- Infinite vertical scrolling gameplay

## Controls

| Key | Action |
|---|---|
| ← / A | Move left |
| → / D | Move right |
| SPACE | Start game |
| R | Restart after game over |
| ` | Toggle debug overlay |

## Technologies

- HTML5
- CSS3
- JavaScript
- p5.js
- HTML Canvas
